# FutureNow Africa brand SVGs

The logo and emblem are genuine editable SVGs. Their named groups separate the
sunrise, abstract Africa-inspired landform, seedling, accent details, and
wordmark. The landform is expressive rather than a geographically exact
continent outline.

- futurenow-africa-logo.svg is for light surfaces.
- futurenow-africa-logo-dark.svg is for dark surfaces.
- futurenow-africa-mark.svg is the standalone emblem.
- futurenow-africa-mark-dark.svg adds an off-white edge for dark surfaces.

The horizontal wordmark remains editable SVG text and requests Cantarell first,
then Arial and a generic sans-serif. If Cantarell is not available in another
editor or export workflow, substitute a humanist sans-serif with a similar
rounded, open character and retain the existing letter spacing.
